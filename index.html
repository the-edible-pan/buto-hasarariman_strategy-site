コマンド

キー アクション 説明
← / → 歩き移動 左矢印で左へ、右矢印で右へ歩く
↓ しゃがみ 低い攻撃を避けることができる
↓ + ← / → しゃがみ移動 しゃがんだまま左右に移動できる(しゃがまないときよりも遅い)
↑ 中ジャンプ 敵、障害物を飛び越える(ジャンプ中、足の当たり判定が小さくなる)
G パンチ 素早い近距離攻撃
K キック 少しリーチの長い攻撃
H ハンマー 強力だが隙が大きい攻撃(ロッカーや扉を破壊可能)
M ムーンサルトキック かなり遠距離の強攻撃が出せるがクールタイムが長い。足の先端に当たり判定があり、一瞬だけ無敵時間がある。
Q かかと落とし 攻撃力最強。(まれに自爆)
L 上を見る 立ち止まり上の階を少し見ることができる
↓ + G しゃがみパンチ しゃがみながらパンチできる
↓ + K しゃがみキック しゃがみながらキックできる
D + ← / → 走り移動 普通の移動よりも速く動くことができる
E + ↓ 体育座り しゃがみよりも小さくなるが動けなくなる
J + ↑ 大ジャンプ 天井にぶつかるぐらいジャンプ力があがる
R リスタート 死亡した後、再開できる
Space スペース スタートしたり、トイレに入ったりなどに使う
Delete セーブ消去 自動セーブされているデータをすべて消す
_ Shift + P ：ペン投げ

フロア

Start：武闘派サラリーマン

Spaceを押してスタート。
画面をクリックしていないと反応しない可能性がある。

Floor1：受付

近づくと受付嬢に殺される。
しゃがみをしながら移動することで安全に近づける。
しゃがみパンチを連打することで倒せる。
その後の階段でつまづくと死ぬ。ジャンプで慎重に上る必要がある。

Floor2：中2階

出入り口の前でSpaceを押すことでトイレに入れるが女性用トイレに入ると死ぬ。

Floor2：トイレ

扉の前でSpaceを押すと扉を開ける。ただし、左端の扉は開けられない。

Floor2：オフィス

・G(12回)もしくはK(6回)の連打
・G(2回)もしくはK(1回)を当ててからQ(1回)を当てる

Floor3：給湯室

方法1
・攻撃をジャンプでよけた後に近距離で攻撃しながら画面端に押し付ける。 敵が逆の画面外から出てきたらまた繰り返し。

Floor4：掃除おばさん

掃除おばさん1
移動、ジャンプをしなければ、敵から攻撃してくることはない。 Mを3回当てれば倒せる。

Floor5：会議室

方法1
ジャンプでよけた後、すぐに敵の背後をとり攻撃、を繰り返す。
方法2
敵が向かってきているところにぎりぎりでMの無敵判定を合わせると攻撃が利かなくなる。

Floor6：事務所

とにかく、よける。ゴミ箱とゴミ箱の間をよけられるようにならないときつい。

Floor7：ジム

敵の攻撃は急な突進攻撃とフェイントの突進攻撃の2種類ある。フェイントの突進攻撃がきたら厳しい。
最初が急な突進攻撃の時、攻撃が終わった後、パンチやキックで攻撃しながら敵を左に押し滑らせて距離を離す。 その後、急な突進攻撃がきたらQで倒せる。

Floor8：掃除おばさん

掃除おばさん2
Mで攻撃を当てる。ジャンプでおばさんの頭の上に乗ってクールタイムを待つとともに敵の攻撃をよける。を繰り返す。

Floor9：廊下

敵の攻撃してくる距離よりも近く、敵の攻撃当たり判定よりも遠い絶妙な距離を取り続けることで、 敵の攻撃クールタイムの間に攻撃することができる。

Floor10：課長室

吐いてくる炎をよけ、しゃばみパンチでち〇ぽを殴ると一撃で倒せる。

Floor11：休憩室

とにかく、よける。

Floor12：掃除おばさん

掃除おばさん3
プレイヤーが離れていると雑巾を投げてきて、近いと近距離攻撃をしてくる。 ちょうどいい距離感を保つことで一方的にMを当てられる。

Floor13：多目的室

とにかく、よける。しゃがみでよけるよりもジャンプでよけるほうが良い。

Floor14：開発室

よけてMをあてる。

Floor15：ラウンジ

D + ← / →による走り移動によって、飛び越える。

Floor16：掃除おばさん

掃除おばさん3
プレイヤーが離れていると雑巾を投げてきて、近いと近距離攻撃をしてくる。 ちょうどいい距離感を保つことで一方的にMを当てられる。

Floor17：制御室

KとQを1回ずつあてる。

Floor18：宴会場

タイミングよくJ + ↑で攻撃をよけると敵が勝手に死ぬ。

Floor19：ロッカールーム

ロッカーの右隣りにいる状態でHを押すとロッカーを開けることができる。9個のうち1つに破壊光線を出す敵がいる。 その敵が入ったロッカーだけを残すことで次に進める。

Floor20：次長室

とにかくよけて、攻撃を当てて倒す。

Floor21：大会議室

とにかく、よける。

Floor22：入館ゲート

よけてMを当て続ける。

Floor23：保育所

ジャンプでよける。

Floor24：掃除おばさん

掃除おばさん4
攻撃をよけて、敵のクールタイム中に攻撃する。

Floor25：非常階段

まず、ジャンプして箱の上に上がった後、手裏剣のタイミングがいいときに一気に階段を上る。

Floor26：資材倉庫

とにかく、よける。

Floor27：応接室

視界が悪くなるが敵自体の行動は突進だけなため、よけて攻撃する。階段は慣れ。

Floor28：掃除おばさん

掃除おばさん5
攻撃をよけて、敵のクールタイム中に攻撃する。

Floor29：更衣室

D + ← / →とJ + ↑を連打することで突破し、敵を殴るだけ。

Floor30：部長室

攻撃をよけて、敵のクールタイム中に攻撃する。

フロアの隠し要素
  • Floorで4の倍数に現れる掃除おばさんは、一つ前の階からJ + ↑で大ジャンプ頭突きで安全に倒すことができる
  • 最上階に社長はいない。まず、最上階のエスカレーターでFloor1に戻り再び2階のトイレに向かう。
    そして、最初は開かなかった左端の扉を連打することで開くことができるようになっている。
    その中に社長は座っており、倒せる。
